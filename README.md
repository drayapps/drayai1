# DRAY·AI — עוזר אישי קולי 🤖

עוזר אישי בסגנון ג'רביס, בעברית מלאה (RTL), שנבנה עבור **Yakir Dray**.
רץ כולו בדפדפן — בלי שרת, בלי התקנה. חי בכתובת: **https://drayai.vercel.app**

## מבנה הפרויקט

| קובץ | תפקיד |
|---|---|
| `index.html` | מבנה הדף — כותרת, ליבה, תמלול, שורת קלט, פאנלים |
| `style.css` | כל העיצוב — ערכת נושא כחולה־זוהרת, אנימציות, רספונסיביות |
| `script.js` | כל הלוגיקה — מוח, קול, זיכרון, יומן, התראות |

## 🧠 המוח

- **Groq · Llama 3.3 70B** עם **סטרימינג בזמן אמת** — התשובה נכתבת מילה־מילה תוך כדי חשיבה.
- המפתח נשמר רק במכשיר (localStorage) ולא נשלח לשום מקום מלבד Groq. הזנה דרך ⚙.
- מודע לתאריך ולשעה הנוכחיים בכל בקשה.
- כפתור "שלח" הופך ל"עצור" בזמן חשיבה; Escape או לחיצה על הליבה מבטלים הכול.

## 🎤 קול

- **דיבור → טקסט**: זיהוי דיבור מובנה של הדפדפן עם הפעלה־מחדש אוטומטית אחרי שקט.
  אם שירות הזיהוי לא זמין (שגיאת network) — **מעבר אוטומטי להקלטה + תמלול Whisper** דרך Groq.
- **טקסט → דיבור**: הקראה בקול עברי, עם **כתוביות חיות** — המילים על המסך נדלקות בדיוק בקצב הדיבור.
- **מצב שיחה רציפה** ("שיחה"): אחרי שהעוזר מסיים לדבר הוא חוזר להקשיב לבד.
- מד עוצמה אמיתי מהמיקרופון מזין את אנימציית הליבה.

## 💾 זיכרון

- **ארכיון תמידי** — כל שיחה נשמרת (עד 1,000 הודעות); "נקה" מנקה רק את התצוגה.
- **יומן קובץ אוטומטי** — עם תיקייה מחוברת, כל שיחה נכתבת ל-`DRAY-LOG.md` עם חותמת זמן.
- **"תזכור ש..."** — עובדות שנשמרות לתמיד ונכנסות להקשר של המודל בכל שיחה עתידית.
- **תקציר נושאים** מהשיחות האחרונות מוזרק גם הוא למודל — הוא זוכר על מה דיברתם.
- `/ייצוא` — הורדת כל הארכיון כקובץ Markdown בלחיצה.

## 📅 יומן ותזכורות (בעברית חופשית, בלי מודל)

- "קבע מחר ב-14:00 רופא שיניים" — מבין היום/מחר/מחרתיים/ביום שלישי + שעות.
- "תזכיר לי בעוד 10 דקות להוציא כביסה" — טיימר ששורד רענון.
- "מה יש לי היום / מחר / השבוע" · `/יומן` · `/יומן מחק 1`.
- כשמגיע הזמן — תזכורת **בקול**, בתמלול ובפעמון.

## 📂 קבצים (File System Access)

- `/תיקייה` — חיבור תיקייה אמיתית מהמחשב (ההרשאה נשמרת בין ביקורים).
- `/קבצים` — מה יש בתיקייה · `/קרא <שם>` — קריאת קובץ טקסט וסיכומו במוח.

## 🖥️ שכבת Jarvis — ניטור עצמי

- **פקודות מקומיות** שעונות מיד, בלי רשת: `/סטטוס` · `/בריאות` · `/התראות` · `/עזרה`.
- **מנוע התראות P0–P3**: קריטי (מפתח חסר) נפתח מיד; אזהרות (רשת, מיקרופון) בתמלול; השאר בפעמון 🔔 עם מונה. כפתור ✓ לסימון טופל; נפתרות לבד כשהבעיה נעלמת.
- **טלמטריה**: בקשות, טוקנים, שגיאות, זמן תגובה, זמן פעילות.
- לחיצה על "SYS ONLINE" בכותרת = דוח סטטוס מלא.

## ⚡ פקודות מהירות ועוד

- "מה השעה" / "מה התאריך" — תשובה מיידית בלי מודל.
- "פתח יוטיוב / גוגל / ג'ימייל / וואטסאפ / מפות / ספוטיפיי" או כל דומיין.

## 🎨 עיצוב וחוויה

- ליבת קנבס חיה שמגיבה למצב: standby / listening / processing / speaking.
- אנימציות לפי עקרונות Emil Kowalski: easing curves חזקים, scale בלחיצה, כניסות עדינות, stagger לצ'יפים, אינדיקטור הקלדה.
- רספונסיבי מלא — במובייל התמלול נפתח מכפתור 💬; תמיכה ב-prefers-reduced-motion.
